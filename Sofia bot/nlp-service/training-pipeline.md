# Пайплайн обучения модели определения выгорания

## Обзор

Пайплайн реализует multi-task нейронную сеть на базе `RuBERT` для одновременного измерения уровня профессионального выгорания по трём валидированным методикам.

```
Текст → [RuBERT Encoder] → [Shared FC Layer] → [Task Heads] → Оценки по шкалам
                                                        ├── MBI (3 шкалы)
                                                        ├── SMBM (3 шкалы)
                                                        └── OLBI (2 шкалы)
```

---

## Методики измерения выгорания

### 1. MBI — Maslach Burnout Inventory (MBI-HSS)

**Авторы:** Christina Maslach, Susan E. Jackson  
**Описание:** Золотой стандарт диагностики выгорания, наиболее валидированный инструмент (5000+ публикаций).

| Шкала | Сокращение | Кол-во пунктов | Диапазон |
|-------|-----------|----------------|----------|
| Эмоциональное истощение (Emotional Exhaustion) | EE | 9 | 0–54 |
| Деперсонализация (Depersonalization) | DP | 5 | 0–30 |
| Редукция профессиональных достижений (Reduced Personal Accomplishment) | PA | 8 | 0–48 |

**Интерпретация MBI:**

| Уровень | EE | DP | PA |
|---------|-----|-----|-----|
| Низкое выгорание | ≤16 | ≤6 | ≥39 |
| Среднее выгорание | 17–26 | 7–12 | 38–34 |
| Высокое выгорание | ≥27 | ≥13 | ≤33 |

**Ключевые пункты опросника:**
- EE: «Я чувствую эмоциональную опустошённость», «Я чувствую себя измотанным к концу рабочего дня»
- DP: «Я стал более циничным в отношении того, влияет ли моя работа на мир», «Мне всё равно, что происходит с некоторыми моими коллегами»
- PA: «Я могу эффективно решать проблемы на работе», «Я чувствую, что вношу полезный вклад в работу»

---

### 2. SMBM — Shirom-Melamed Burnout Measure

**Авторы:** Arie Shirom, Shraga Melamed  
**Описание:** Израильская методика, сфокусированная на физиологических и когнитивных аспектах выгорания.

| Шкала | Сокращение | Описание |
|-------|-----------|----------|
| Физическая усталость (Physical Fatigue) | PF | Ощущение утомления, низкая энергия |
| Когнитивное истощение (Cognitive Weariness) | CW | Трудности с концентрацией, «туман в голове» |
| Эмоциональное истощение (Emotional Exhaustion) | EE | Чувство опустошённости |

**Интерпретация SMBM:**

| Средний балл | Уровень |
|-------------|---------|
| 1.00–2.59 | Низкое |
| 2.60–3.39 | Среднее |
| 3.40–5.00 | Высокое |

---

### 3. OLBI — Oldenburg Burnout Inventory

**Авторы:** Evangelia Demerouti, Arnold Bakker  
**Описание:** Европейская альтернатива MBI, валидирована для разных культур.

| Шкала | Сокращение | Описание |
|-------|-----------|----------|
| Истощение (Exhaustion) | EX | Физическое и эмоциональное истощение |
| Отстранённость (Disengagement) | DG | Дистанцирование от работы, потеря интереса |

**Интерпретация OLBI:**

| Шкала | Низкий | Средний | Высокий |
|-------|--------|---------|---------|
| Истощение | ≤2.0 | 2.1–2.9 | ≥3.0 |
| Отстранённость | ≤1.5 | 1.6–2.2 | ≥2.3 |

## Архитектура модели

```
Вход: текст (до 256 токенов)
    │
    ▼
┌─────────────────────────────────────────────┐
│              RuBERT-base Encoder             │
│         (768 скрытых измерений)              │
└─────────────────────────────────────────────┘
    │
    ▼ [CLS токен]
┌─────────────────────────────────────────────┐
│            Shared FC Layer                  │
│  Linear(768 → 384) → GELU → Dropout(0.1)    │
└─────────────────────────────────────────────┘
    │
    ├──────────────────┬──────────────────────┐
    ▼                  ▼                      ▼
┌─────────┐      ┌─────────┐          ┌─────────┐
│ MBI Head│      │SMBM Head│          │OLBI Head│
│(384→3)  │      │(384→3)  │          │(384→2)  │
└─────────┘      └─────────┘          └─────────┘
    │                  │                   │
    ▼                  ▼                   ▼
  [EE,              [PF,              [EX,
   DP,               CW,               DG]
   PA]               EE]
```

**Параметры модели:**
- Base encoder: ~110M параметров (заморожен при fine-tuning)
- Trainable: ~1.2M параметров
- Выход: 8 значений в диапазоне 0–100

## Подготовка данных для обучения

### Формат датасета

```python
# texts: список текстов (сообщений, комментариев, транскриптов)
texts = [
    "Я так устал от этой работы...",
    "Отличный день, всё получается!",
    ...
]

# labels: numpy array формы (n_samples, 8)
# Порядок: [EE_MBI, DP_MBI, PA_MBI, PF_SMBM, CW_SMBM, EE_SMBM, EX_OLBI, DG_OLBI]
labels = np.array([
    [75.0, 45.0, 25.0, 70.0, 65.0, 75.0, 70.0, 60.0],  # высокий уровень выгорания
    [15.0, 5.0,  80.0, 15.0, 10.0, 15.0, 15.0, 10.0],  # норма
    ...
])
```

### Источники данных

1. **Корпоративные чаты (Telegram, Slack)**
   - Тексты сообщений
   - Предварительная разметка через опросники или экспертную оценку

2. **Психологические исследования**
   - Публичные датасеты (при наличии)
   - Данные из исследований (с разрешения авторов)

3. **Самоотчёты сотрудников**
   - Текстовые ответы на открытые вопросы
   - Анкетирование по шкалам

### Разметка данных

Для получения меток рекомендуется:

1. **Параллельный сбор:** Сбор текстов и заполнение опросников одними и теми же сотрудниками
2. **Экспертная разметка:** Психологи оценивают тексты по шкалам
3. **Proxy-разметка:** Использование косвенных признаков (количество больничных, текучесть)

### Пример кода для сбора данных

```python
from app.training_pipeline import BurnoutMultiTaskTrainer, TrainingConfig

# Подключение к БД проекта
# texts, labels = collect_from_database()

config = TrainingConfig(
    base_model="ai_forever/ruBert-base",
    batch_size=16,
    epochs=10,
    learning_rate=2e-5,
    output_dir="./models/burnout_final"
)

trainer = BurnoutMultiTaskTrainer(config)

# Обучение
trainer.train(texts, labels)

# Сохранение
trainer.save_model()
```

## Валидация модели

### Метрики качества

| Метрика | Описание | Целевое значение |
|---------|----------|------------------|
| MAE | Средняя абсолютная ошибка | < 10 баллов |
| RMSE | Среднеквадратичная ошибка | < 15 баллов |
| Corr | Корреляция с опросниками | > 0.7 |

### Тестирование

```python
# Разделение данных
train_texts, test_texts, train_labels, test_labels = ...

# Предсказания
predictions = trainer.predict(test_texts)

# Метрики по шкалам
for i, scale in enumerate(["EE_MBI", "DP_MBI", "PA_MBI", ...]):
    mae = mean_absolute_error(test_labels[:, i], predictions[:, i])
    print(f"{scale}: MAE = {mae:.2f}")
```

## Ограничения и рекомендации

### Ограничения методик

1. **Субъективность:** Все методики основаны на самоотчётах
2. **Культурная специфика:** Интерпретации норм требуют адаптации
3. **Короткие тексты:** Для надёжной оценки нужно минимум 5–10 сообщений
4. **Контекст:** Оценка по одному тексту менее надёжна, чем по истории

### Рекомендации

1. **Накапливать историю:** Оценка по скользящему окну (неделя/месяц)
2. **Использовать консенсус:** Среднее по MBI, SMBM, OLBI
3. **Валидировать на своих данных:** Адаптировать пороги после сбора данных
4. **Не принимать решений по одной метрике:** Комплексная оценка состояния
